# Три мови на mlohaza.com: як влаштовано і чому

Рішення від 25.10.2026, v3.4. Інструкція з редагування в `src/README.md`.

## Що обрали

**Окремі статичні сторінки для кожної мови, зібрані з одного джерела.**

- Англійська в корені (`/`), польська в `/pl/`, українська в `/ua/`. Порядок мов скрізь EN → PL → UA.
- Кожна сторінка кожною мовою має свою адресу, свій `<title>`, опис, `canonical` і `hreflang`.
- Тексти лежать окремо для кожної мови (`src/pages/<мова>/`), а шапка, футер, панель запису, стилі й JavaScript спільні. Зміна дизайну робиться один раз для всіх мов.

## Чому так

**SEO.**
- Google індексує кожну мовну версію окремо, тільки якщо в неї своя адреса. Переклад на льоту через JavaScript (як на NetConnect з `data-i18n`) показує Google лише одну мову.
- `hreflang` каже Google, яку версію показати поляку, українцю чи англомовному відвідувачу. Без нього три версії конкурують між собою як дублікати.
- Папки (`/pl/`, `/ua/`) на одному домені збирають усю вагу посилань на mlohaza.com. Піддомени чи окремі домени ділили б її на три сайти.
- Англійська в корені як `x-default`: це версія для всіх, чия мова не польська й не українська. Автоматичного переадресування за мовою браузера немає навмисно, бо робот Google заходить без мови й бачив би лише одну версію.
- Адреси сторінок перекладено (`o-mnie`, `pro-mene`), бо слово в адресі трохи допомагає пошуку рідною мовою. `calm-ops` однакове всюди, бо це назва методу.

**Редагування.**
- Одне джерело на мову: щоб змінити текст польською, відкриваєте `src/pages/pl/...` і бачите всю сторінку. Тексти не розкидано по ключах у JSON.
- Спільне винесено в `layout.html` і `i18n/*.json`, тож нова кнопка в меню з'являється на всіх 15 сторінках після однієї зміни.
- Збірка перевіряє себе: зупиняється, якщо для якоїсь мови бракує сторінки чи рядка перекладу.
- Без фреймворку й залежностей: тільки Python 3. Хостинг будь-який (VPS, Cloudflare Pages, Netlify, GitHub Pages).

## Чек-лист SEO перед запуском

1. **Домен.** У `src/site.json` поле `base` (зараз `https://mlohaza.com`). Після зміни перезібрати.
2. **Сервер.** `/pl/` і `/ua/` мають віддавати `index.html`. Так поводиться будь-який статичний хостинг.
   - Бажано: 301 з `/index.html` на `/`.
   - Бажано: HTTPS і одна форма домену (з `www` або без).
3. **Google Search Console.**
   - Додати домен.
   - Надіслати `https://mlohaza.com/sitemap.xml`.
   - Через тиждень перевірити звіт «Міжнародне націлювання» на помилки hreflang.
4. **Google Business Profile** на «Mykhailo Lohaza», Познань: ім'я й адреса мають збігатися з даними на сайті.
5. **Аналітика.** Після вибору сервісу оновити політику приватності трьома мовами. Зараз там написано, що cookies немає.
6. **Нові сторінки** додавати трьома мовами одразу. Якщо якоїсь мови ще немає, не публікувати сторінку, ніж публікувати без перекладу.

## Тексти, які варто показати носію мови

- Польська версія (уся). Звертання на «Ty» («Twój zespół»), як у сучасному польському B2B. Якщо потрібен офіційніший тон, змінюємо на «Państwo».
- Юридичні сторінки трьома мовами: перевірка юриста, список сервісів, умови повернення оплати.
