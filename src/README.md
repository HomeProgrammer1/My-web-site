# Джерела сайту (src/) → готовий сайт (site/)

Сайт має три мовні версії, кожна сторінка — окремий статичний HTML-файл. `site/` збирається з цієї папки однією командою, тому руками в `site/*.html` нічого не правимо: наступна збірка перезапише зміни.

```
python3 src/build.py        # збирає 15 сторінок, lang/*.js, sitemap.xml, robots.txt
python3 -m http.server -d site   # перегляд на http://localhost:8000
```

Потрібен тільки Python 3, без пакетів.

## Структура

| Що | Де | Коли правити |
|---|---|---|
| Тексти сторінок | `pages/en/*.html`, `pages/pl/*.html`, `pages/ua/*.html` | Будь-яка зміна тексту чи блоку на сторінці |
| Заголовок і опис для Google | перші рядки кожного файлу сторінки (`title:`, `description:`) | SEO-тексти конкретної сторінки |
| Шапка, футер, панель запису | `layout.html` (спільний для всіх сторінок) | Структура, однакова на всіх сторінках |
| Тексти шапки, футера, панелі запису й інтерактивів | `i18n/en.json`, `i18n/pl.json`, `i18n/ua.json` | Меню, кнопки, повідомлення калькулятора й демо |
| Мови, адреси сторінок, якорі | `site.json` | Нова сторінка, нова мова, зміна адреси |
| Стилі й логіка | `site/styles.css`, `site/main.js` | Одні файли для всіх мов |

Порядок мов скрізь однаковий: **EN → PL → UA**. Англійська лежить у корені сайту, польська в `/pl/`, українська в `/ua/`.

## Адреси сторінок

| Сторінка | EN | PL | UA |
|---|---|---|---|
| Головна | `/` | `/pl/` | `/ua/` |
| Метод Calm Ops | `/calm-ops.html` | `/pl/calm-ops.html` | `/ua/calm-ops.html` |
| Про мене | `/about.html` | `/pl/o-mnie.html` | `/ua/pro-mene.html` |
| Політика приватності | `/privacy.html` | `/pl/polityka-prywatnosci.html` | `/ua/polityka-pryvatnosti.html` |
| Умови | `/terms.html` | `/pl/regulamin.html` | `/ua/umovy.html` |

## Мітки в шаблонах

- `{{root}}` — шлях до кореня (`''` або `../`), для картинок: `src="{{root}}img/me.jpg"`.
- `{{href:about}}` — посилання на сторінку тією ж мовою; `{{href:home#calc}}` — з якорем (ключі якорів у `site.json`).
- `{{t:nav.about}}` — рядок з `i18n/<мова>.json`.

## Як додати сторінку

1. Додати рядок у `site.json` → `pages` з адресою для кожної мови (і пріоритет у `sitemap`).
2. Створити `pages/en/<ключ>.html`, `pages/pl/<ключ>.html`, `pages/ua/<ключ>.html` з блоком `title`/`description` зверху.
3. Додати посилання в `layout.html`, якщо сторінка має бути в меню чи футері.
4. `python3 src/build.py`. Збірка зупиниться з помилкою, якщо бракує файлу, рядка перекладу або мітка лишилась незаповненою.

Якщо змінити адресу сторінки в `site.json`, збірка сама прибере старий файл із `site/`. На живому сайті для старої адреси потрібен 301-редирект.

## Що збірка робить для SEO

- `<html lang>`: `en`, `pl`, `uk`.
- `canonical` на кожній сторінці.
- `hreflang` для en, pl, uk і `x-default` (англійська).
- Open Graph з `og:locale` і альтернативами.
- Розмітка Person (schema.org) на головних.
- `sitemap.xml` з усіма альтернативами й `robots.txt`.

Перед запуском (див. `docs/i18n.md`): домен у `site.json` → `base`, сервер віддає `index.html` для `/pl/` і `/ua/`, сайт додано в Google Search Console, sitemap надіслано.
